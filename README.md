# 視覚障害者向けナビゲーション デモ

このリポジトリは、私の卒業研究で取り組んだ「RGB-Dカメラとマイクアレイを用いた視覚障害者向けナビゲーションシステム」のデモコードをまとめたものです。
研究のコアとなる画像認識と音源方向推定の部分を、動かせる形で公開しています。

## 研究テーマの概要
視覚障害者の方が安全に歩行できるように、周囲のランドマーク（看板や横断歩道、自動販売機など）を検出し、音源の方向を特定するシステムの研究を行いました。
本番のシステムは手法が重たく複雑であるものもあるため、ここでは主要なアルゴリズムのみを体験できるようにしています。

## 使用技術
- Python 3.10
- YOLO11 (画像認識)
- PyTorch / Torchaudio (音響処理)
- OpenCV

## 自分が実装した範囲
研究開発において、私は主に以下の実装を担当しました。
- YOLO11を用いたランドマーク検出モデルの学習と推論パイプラインの構築
- マイクアレイから得られた音声データのスペクトログラム変換処理
- GCC-PHATアルゴリズムを用いた音源方向推定（DOA）の実装

## 工夫した点
- YOLO11をリアルタイムで動作させるための推論速度の最適化を行いました。
- 音源方向推定では、ノイズ環境下でも精度を落とさないためのフィルタリング処理を工夫しました。

## 課題
- 音源方向推定は依然としてノイズの影響が大きく、精度が不安定です。
- データセットは自ら作成しているため、実環境での性能評価には限界があります。
- 今後実証試験を行う予定です。

## 実行方法
リポジトリをクローンした後、以下の手順でデモを実行できます。

```bash
pip install -r requirements.txt
python examples/run_image_demo.py
python examples/run_audio_demo.py
```
