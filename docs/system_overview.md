# システム全体の概要

本ページでは、卒業研究で開発したナビゲーションシステムの全体像について説明します。研究の詳細を公開することはできないため、本リポジトリにはサンプルコードのみを示しています。

## 研究背景
視覚障害者の方の外出を支援するためには、周囲の危険物やランドマークを正確に把握することが重要です。既存の白杖や盲導犬に加えて、AI技術を用いてより多くの環境情報を提供するシステムの開発を目指しました。

## 研究目的
RGB-Dカメラとマイクアレイを組み合わせることで、視覚と聴覚の両方の情報を活用し、より安全で正確なナビゲーションを実現することを目的としています。

## システムの入力と出力

### 入力データ
- RGB画像: カメラからの通常のカラー画像です。
- Depth画像: 対象物までの距離情報を持つ画像です。
- マイクアレイ音声: 複数マイクから得られた音声データです。

### 出力データ
- ランドマーク種別: 信号機、横断歩道、点字ブロックなどの種類です。
- 対象物までの距離: 検出したランドマークまでの物理的な距離です。
- 音源方向: 車の走行音や信号機の音の鳴っている方向です。

## 全体の処理フロー
1. カメラとマイクからデータを同時に取得します。
2. 画像データはYOLOに入力され、ランドマークの位置と種類を特定します。
3. 音声データは周波数解析され、音源の方向を推定します。
4. これらの情報を統合し、ユーザーに音声で通知します。

現在は、実地試験に向けてモジュールごとの検証を進めている段階です。
