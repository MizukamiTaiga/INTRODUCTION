# 技術的な詳細と工夫点

本ページでは、システムの実装において使用した技術や、特に苦労して工夫した点についてまとめました。

## YOLOを用いた画像ランドマーク検出
物体検出には、処理速度と精度（主にPrecision）のバランスが良いYOLOを採用しました。
- 課題: 歩行中のブレにより検出精度が落ちることがありました。
- 工夫: データ拡張を工夫し、ブレた画像でも頑健に検出できるようにモデルをファインチューニングしました。

## RGB-DカメラのDepth情報を用いた距離取得
検出したバウンディングボックス内のDepthピクセル値の中央値を取得することで、対象物までの距離を計算しています。ノイズを除去するために、外れ値を除外する処理を追加しました。

## 音響データのスペクトログラム解析
音声の特徴を捉えるため、STFTスペクトログラムだけでなく、人間の聴覚特性に近いLog-Melスペクトログラムを生成して比較検証を行いました。結果として、環境音の分類にはLog-Melスペクトログラムが有効であることが確認できました。

## GCC-PHATによる音源方向推定
複数のマイク間の到達時間差（TDOA）を利用して音源方向を推定するGCC-PHATを実装しました。
- 課題: 雑音が多い環境では、相互相関のピークが曖昧になり誤検知が発生しました。
- 工夫: 周波数重み付け処理を適用することで、反射音の影響を抑え、推定精度を向上させることに挑戦しています。
